# 给自己的高位下拉和深蹲录像做标注

从「课堂试测」打开「本地视频标注」，或访问 `/#/label`。这页读取自己选择的 MP4 或 WebM，只显示源视频和时间线。标注者看不到模型预测，视频和标注都留在本机。离开前请下载 JSON。

## 采集与两人标注

- 取得拍摄者和出镜者同意。建议从 6 人每人 2 段开始，镜位包含标准固定侧位和有意遮挡的困难条件。每段先做 3 次个人校准，再做预先约定的动作，例如 5 次。让同一人的所有录像只落入开发集或测试集的其中一个集合。
- 为每段分配无个人信息的编号，例如 `P04-LP-02`。A、B 在各自的空白页面选择同一视频、同一编号和动作，独立标完整段，分别导出 `P04-LP-02-A.json`、`P04-LP-02-B.json`。若要测泛化，先冻结规则和测试集。
- 「起点」取可见的顶端开始动作，「最低点」取该次下拉或屈膝的最深处，「返回点」取回到起始位置的时刻。播放速度可降到 0.25×。步进按钮每次移动 0.04 秒，遇到可变帧率视频，应以暂停后的画面为准。标注按时间先后录入，可点击记录回看最低点，可撤销最近一步。
- 关节和完整往返都看得清时选「完整可见」。确实看见完整往返但较该人的校准动作明显偏浅时选「幅度偏短」。该标签表示人工观察；精确的百分比由模型相对个人校准范围计算。无法判断的完整候选选「无法确定」，片头截断、遮挡或切镜选「排除区间」并标起止时间。
- 保留两份独立原稿。复核时选择原视频，导入其中一份 JSON，与第二份对照，核对分歧、调整标签，标注者选择「复核定稿」。已看完整段后勾选确认再导出。导入会核对文件 SHA-256 与时长；仅文件名相同不能代替内容一致。
- 当前事件评分器假定全片有连续、完整的参考序列。草稿、仍有不确定动作或排除区间的片段在导出时会保留所有人工标记，`windows` 与 `visualCycles` 为 `null`，评分器跳过整段。若要评测某个连续清晰的片段，先单独裁成文件，再对此文件重新标注并保留它自己的哈希。确认无动作的完整负样本会导出空的 `windows`。

## 用标注跑模型

准备好前端模型并启动本机 Vite 开发服务。以下命令在 `ui/` 运行。把原始片复制到私有目录，以导出 JSON 的 `clips[0].file` 为文件名。这个名字由匿名编号及扩展名组成。文件内容须与标注时完全相同。

```sh
node scripts/compare-models.mjs --models full \
  --manifest /private/path/P04-LP-02-consensus.json \
  --video-dir /private/path/videos \
  --output /private/path/P04-LP-02-full.json

python3 scripts/score-replay.py /private/path/P04-LP-02-full.json \
  --manifest /private/path/P04-LP-02-consensus.json
```

浏览器和模型依赖的准备步骤见 [预训练模型对照说明](model-comparison.md)。多个定稿可合并在同一份 `{"clips":[...]}` 中，每个编号只保留一段。比较模型时用同一批原始文件、标注版本和人物划分。评分的前三个可见参考周期用于校准，后续周期用于计数。人工标注导出的 `annotations` 另存起点、最低点、返回点和人工状态，现有评分器使用 `windows` 做事件对齐；幅度标签仍需单独核对。

## 在定稿前比较 A、B

两位标注者各自在自己的页面勾选「已看完整段并核对全部标记」后导出，允许保留无法确定的段落。在 `ui/` 使用本机 Python 运行下列命令。工具核对视频 SHA-256、动作、时长，以及两个不同的标注者角色。它只读取标注 JSON。

```sh
python3 scripts/compare_labels.py /private/path/P04-LP-02-A.json \
  /private/path/P04-LP-02-B.json --return-tolerance 0.5
```

- 任一人的不确定动作和排除区间先合并成时间掩码，双方与其相交的周期均单列。边界刚好相接的两个区间仍可分别处理。
- 在共同可判定部分，先最大化一对一匹配数，再使匹配返回点的绝对时间差总和最小。匹配保持时间顺序，候选须有时间重叠且返回点间隔在给定秒数内。默认 0.5 秒，比较不同视频时须固定这个容差。
- `comparableCounts` 为两人的可比较周期数和计数差，`onlyA`、`onlyB` 为各自未配对的原标注条目序号（从 1 开始）。`matches` 同时列出两人的返回时间及幅度判断。`medianAbsoluteReturnDifferenceSec` 越小表示匹配的返回点越接近，带符号的差值为 B 减 A。没有匹配时，中位数为 `null`。
- 如果总次数相同，仍要检查未配对的条目。例如在人为扰动的示例中，两份都标了 4 次可比较动作，只能对齐 3 次，各有 1 次未配对，匹配返回点绝对差的中位数为 0.15 秒。该示例只验证工具，不能作为参与者数据或人工一致性结论。[合成示例与完整输入](results/label-agreement-synthetic.json)

运行 `python3 -m unittest discover -s scripts -p test_compare_labels.py` 可复现缺标、多标、时间偏移、遮挡与合成示例的检查。
